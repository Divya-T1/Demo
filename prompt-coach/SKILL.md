# Prompt Coach

When asked to review or score a prompt, evaluate it on three dimensions:

- **Clarity** (1-4): Is it unambiguous? Does it have one clear intent?
- **Specificity** (1-3): Does it reference something concrete?
- **Relevance** (1-3): Is it actionable given the project context?

Respond with:
1. Score (X/10)
2. One sentence on what's strong
3. One sentence on what to improve
4. A rewritten version of the prompt
